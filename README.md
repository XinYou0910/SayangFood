# Title of Project: SayangFood
## A modern web app for reducing food wastages.

## Description
SayangFood is a web-based of smart food waste reduction management system that allow household user to manage food inventory
, Browse Food Items, review Food Analytics, view Notifications, Plan Weekly Plan and receive verification through email before resetting their passwords. 

# Main Features
- User registration and email verification
- Manage Food Inventory
- Browsw Food Items
- Food Analytics
- View Notificaitons
- Plan Weekly Plan

# Technology Stack
- Fronttend: HTML, CSS, Javascript
- Backend: PHP
- Database: MySQL
- Tools: XAMPP, PHPMailer, Github
